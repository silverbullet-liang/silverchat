# 跨境数据传输协议

## 一、协议目的与适用范围

### 1.1 为什么需要这份协议

本服务部署在中华人民共和国境外的共享主机上。您注册和使用本服务时，您的账号信息、社交关系、消息密文等数据会从您所在国家/地区传输至境外服务器存储与处理。这构成《中华人民共和国个人信息保护法》所称的“个人信息出境”，也可能构成欧盟《通用数据保护条例》（GDPR）所称的“向第三国传输”。

本协议向您如实说明：传输什么、传给谁、为什么传、如何保护、您有什么权利。

### 1.2 适用场景

本协议适用于您使用本服务全过程中涉及数据出境的环节，包括但不限于：
- 注册时提交账号信息；
- 登录与维持会话；
- 发送与接收消息、上传与下载媒体；
- 添加好友、建立群聊、发布动态；
- 服务器按法律要求留存日志与同意记录。

### 1.3 与其他文件的关系

本协议是《隐私政策》第七节的展开与补充，与《用户协议》《隐私政策》共同构成完整约定。就数据出境事项，以本协议为准；本协议未约定的，适用《隐私政策》。

### 1.4 关键结论（先读这一段）

1. **最敏感的内容不出境**：端到端加密的私钥只存在您的浏览器，从不上传；消息明文在服务器上不存在。
2. **出境的是密文与元数据**：消息与聊天媒体以密文形式出境；账号资料、社交关系、动态等以服务器端加密或明文元数据形式出境。
3. **出境基于您的单独同意**：注册时的勾选即构成《个人信息保护法》第三十九条要求的单独同意。
4. **您可以拒绝或撤回**：拒绝将无法使用本服务；撤回同意的方式是注销账号。

## 二、数据出境的基本情况

### 2.1 传输路径

```
您的浏览器（中国或其他国家/地区）
   │  HTTPS（TLS 1.2+）
   ▼
境外共享主机（主机服务商数据中心）
   ├── MySQL 数据库（账号、关系、消息密文、动态密文）
   ├── 文件目录（聊天媒体密文、动态图片服务器端加密文件、头像）
   └── 主密钥文件（服务器端加密用，位于 Web 根目录之外）
```

数据不经过我们自建的中转服务器，也不传输给广告、统计或数据分析第三方。

### 2.2 境外接收方

| 接收方 | 所在地 | 角色 | 接触的数据 |
|---|---|---|---|
| 主机服务商（境外共享主机提供商） | 以服务商数据中心公告为准 | 基础设施提供方（受托处理者） | 服务器文件系统、数据库、日志、备份（如有） |
| 本服务运营者 | 中华人民共和国 | 个人信息处理者 | 通过管理权限访问数据库与文件 |

本服务**不向其他境外第三方传输**您的个人信息。内置表情图片为部署时离线下载的静态资源，运行时不向 bilibili 或任何第三方发起请求。

### 2.3 存储地点

数据存储于主机服务商提供的数据中心，具体国家/地区以服务商公告为准。由于共享主机的特性，数据中心可能由服务商调整；发生变更时我们将更新本协议并通过站内公告通知。

我们不排除主机服务商在其关联公司或分包商处进行数据备份的可能性，该等情形受其服务条款与隐私政策约束。

## 三、出境数据的范围与分类

### 3.1 出境数据清单

| 数据类别 | 具体内容 | 是否出境 | 存储形态 | 出境目的 |
|---|---|---|---|---|
| 账号标识 | 用户名 | 是 | 服务器端加密 + HMAC 盲索引 | 注册、登录、被搜索 |
| 认证凭据 | 密码哈希、安全问题答案哈希 | 是 | bcrypt 哈希（不可逆） | 身份验证、找回密码 |
| 资料信息 | 昵称、头像、性别、个性签名 | 是 | 昵称与签名加密，头像加密存储，性别明文枚举 | 资料展示 |
| 设备信息 | 设备 ID、User-Agent、公钥 | 是 | 明文 | 多端管理、密钥协商 |
| 登录凭证 | Token 哈希、过期时间 | 是 | SHA-256 哈希 | 维持登录 |
| 网络日志 | IP 地址、请求时间、接口、状态 | 是 | 明文，原则上不超过 90 天 | 安全风控、故障排查 |
| 社交关系 | 好友关系、好友备注、申请附言、群成员关系 | 是 | 关系明文，备注与附言加密 | 通讯录与群聊功能 |
| 群信息 | 群名称、群公告、群昵称、群号 | 是 | 名称/公告/昵称加密 | 群聊功能 |
| 消息内容 | 消息正文、图片、语音、视频、文件 | 是 | **端到端加密密文**，服务器无密钥 | 消息投递 |
| 消息元数据 | 会话 ID、发送者、类型、时间、已读状态 | 是 | 明文 | 消息同步与未读计数 |
| 群会话密钥 | 每位成员的群密钥封装 | 是 | ECDH 封装密文，服务器无法解封 | 群消息加解密 |
| 动态内容 | 动态文字、图片、点赞、评论、可见范围 | 是 | 文字与评论加密，图片服务器端加密 | 动态展示 |
| 合规记录 | 协议版本、同意时间、IP、UA、注销申请 | 是 | 明文，注销后保留 3 年 | 法律合规 |

### 3.2 不出境的数据

| 数据 | 原因 |
|---|---|
| 端到端加密私钥（X25519 / P-256） | 仅在您的浏览器 IndexedDB 中生成与保存，从不上传 |
| 消息明文 | 在您的设备上加密，服务器只收到密文 |
| 聊天媒体的明文 | 在您的设备上加密后上传，服务器只存密文 |
| 密码明文 | 仅在传输时经 HTTPS 保护，服务器只保存哈希 |

### 3.3 元数据的说明

端到端加密保护内容，不保护元数据。以下信息以明文形式出境并存储：谁与谁建立了会话、消息何时发送、消息类型与大小、群成员构成、已读时间。这些元数据是完成消息路由与未读计数所必需的。我们不会将元数据用于画像或广告。

### 3.4 敏感个人信息

本服务不主动收集生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等敏感个人信息。您主动发送的位置消息包含当次坐标，属于您自行提供的内容，以端到端加密形式传输；该坐标不会被服务器解析或留存为独立字段。

## 四、法律依据与合规机制

### 4.1 中华人民共和国法律

1. **《个人信息保护法》第三十八条**：个人信息处理者因业务等需要向境外提供个人信息的，应当具备下列条件之一：通过国家网信部门组织的安全评估；经专业机构进行个人信息保护认证；与境外接收方订立标准合同；法律、行政法规规定的其他条件。
2. **《个人信息保护法》第三十九条**：向境外提供个人信息，应当向个人告知境外接收方的名称、联系方式、处理目的、处理方式、个人信息的种类以及个人向境外接收方行使权利的方式和程序等事项，并取得个人的**单独同意**。
3. **《数据安全法》《网络安全法》**：要求采取技术措施保障数据安全，发生安全事件及时处置与报告。

**我们的合规路径**：本服务为小规模、非商业化的自建服务，当前以**取得您的单独同意**为基础实施出境，并采取本协议第五节的全部保护措施。若服务规模达到法律规定的安全评估或标准合同备案阈值，运营者应当依法补办相应手续；在完成前可能暂停新增用户注册。

### 4.2 欧盟《通用数据保护条例》（GDPR）

若您位于欧洲经济区，我们依据 GDPR 第 49 条第 1 款第 (a) 项（在充分告知风险后取得明确同意）实施传输，并采取第 5 节的技术措施作为补充保障。您有权依据第 8 节行使权利，并有权向所在地监管机构投诉。

### 4.3 其他法域

若您所在国家/地区对数据出境有更严格的要求（如要求本地化存储、事前审批），您应自行评估使用本服务的合规性。**若您所在国家/地区禁止将数据传输至本服务部署地，请勿注册使用。**

### 4.4 我们的声明

我们不会以“规避监管”为目的迁移数据或更换部署地。部署地变更时，我们会更新本协议、重新取得同意，并评估新部署地的法律环境。

## 五、跨境传输的保护措施

### 5.1 加密保护（核心）

| 数据 | 加密方式 | 服务器能否解密 |
|---|---|---|
| 消息正文 | 客户端 X25519/ECDH 协商 + HKDF + AES-256-GCM | 否 |
| 聊天媒体 | 客户端使用会话密钥 AES-256-GCM 加密 | 否 |
| 群消息 | 群密钥由成员间 ECDH 封装分发，消息以群密钥加密 | 否（服务器无法解封） |
| 用户名、昵称、备注、群名、动态文字、评论 | 服务器端 AES-256-CBC + HMAC-SHA256 | 是（持有主密钥） |
| 动态图片、头像 | 服务器端加密存储 | 是 |
| 密码、Token、安全答案 | bcrypt / SHA-256 哈希 | 不可逆 |
| 传输链路 | HTTPS / TLS 1.2+，HSTS | — |

### 5.2 最小化传输

- 只传输完成功能所必需的数据；
- 私钥与消息明文不上传；
- 聊天媒体 7 天后删除，减少境外留存的数据量；
- 不采集手机号、身份证号、通讯录、相册等非必要信息；
- 不接入第三方统计、广告、CDN 脚本。

### 5.3 存储与访问控制

- 主密钥存放在 Web 根目录之外，文件权限 600；
- 数据库仅应用服务器可连接，不对外开放端口；
- 媒体目录禁止脚本执行、禁止目录列表；
- 敏感目录通过服务器配置拒绝直接访问；
- 管理账号仅运营者本人掌握，启用强密码。

### 5.4 删除与到期处理

| 数据 | 处理 |
|---|---|
| 聊天媒体 | 上传后 7 天由惰性清理任务删除文件，消息标记为“内容已过期” |
| 动态图片 | 7 天后删除文件 |
| 登录 Token | 7 天过期，登出即删除 |
| 安全日志 | 原则上不超过 90 天 |
| 注销账号 | 敏感字段立即清空，媒体立即删除，关系解除 |
| 同意记录 | 注销后保留 3 年（法定义务） |

### 5.5 对主机服务商的约束

我们通过以下方式降低主机服务商接触数据带来的风险：
- 选择提供基本隐私承诺的共享主机服务商，并遵守其服务条款；
- 消息与聊天媒体采用端到端加密，服务商即便读取文件也只能得到密文；
- 服务器端加密字段的密钥与数据库分离存放，仅通过常规主机管理界面无法直接获得明文；
- 不在服务器上保存任何明文凭据；
- 定期检查文件权限与目录暴露情况。

**诚实声明**：共享主机的特性决定了主机服务商在技术上具备接触服务器文件系统的能力。端到端加密的数据不受影响；服务器端加密的数据在“服务商同时取得密钥文件与数据库”的极端情形下可能被解密。这一风险无法通过应用层手段完全消除，请您知悉。

### 5.6 安全评估与审计

- 上线前进行安全检查：越权访问、注入、上传、加密实现、会话管理；
- 定期检查依赖与配置，修复已知漏洞；
- 记录并复核安全事件，持续改进。

## 六、境外接收方的义务

主机服务商作为受托处理者，其义务来源于其服务条款与适用法律。我们要求其：
1. 仅为提供主机服务处理数据；
2. 采取合理的安全措施；
3. 不将数据用于自身营销目的；
4. 在服务终止时按约定处理数据。

我们与主机服务商之间不涉及您的消息明文，因为服务器上不存在明文。

## 七、再传输

1. 我们**不会**将您的个人信息再传输给其他境外第三方用于营销、分析或广告。
2. 因功能必需向其他用户展示的信息（昵称、头像、动态等），属于您主动使用服务的结果，按您设置的可见范围传输。
3. 若未来因功能需要引入新的境外服务方（如对象存储、邮件服务），我们会提前更新本协议与《第三方共享清单》，并重新取得您的同意。

## 八、您的权利与行使方式

### 8.1 知情权

您有权了解出境数据的类别、接收方、目的与保护措施，本协议即为该告知。

### 8.2 单独同意

您在注册与登录时勾选同意本协议，即构成对数据出境的单独同意。**该同意独立于其他协议，不被默认勾选。**

### 8.3 拒绝的后果

您有权拒绝同意。拒绝后无法完成注册或登录，即无法使用本服务。这是因为本服务没有境内部署节点，数据出境是提供服务的前提。

### 8.4 撤回同意

您可随时通过**注销账号**撤回同意。注销后：
- 我们将停止处理您的个人信息；
- 敏感字段立即清空，媒体文件立即删除；
- 消息记录匿名化保留，以维持对端对话结构；
- 同意记录按法律要求保留 3 年后删除。

撤回同意不影响撤回前基于同意已进行的处理活动的效力。

### 8.5 查阅、更正、删除与复制

行使方式与《隐私政策》第八节一致。您可在应用内自助完成大部分操作；需人工处理的，以书面形式提交，我们将在 15 个工作日内答复。

### 8.6 投诉与救济

1. 您可向所在地网信、市场监管等监管部门投诉；
2. 您可依法向人民法院提起诉讼；
3. 若您位于欧洲经济区，可向所在地数据保护监管机构投诉。

## 九、数据泄露与应急响应

1. 发现数据泄露、篡改、丢失的，我们立即采取补救措施（重置密钥、封禁入口、修复漏洞、隔离数据）。
2. 评估泄露数据的类别与影响：由于消息为端到端加密，泄露的通常是与账号、关系、元数据相关的信息。
3. 在发现后尽快（原则上不超过 72 小时）通过站内公告告知受影响用户，说明事件情况、可能影响、已采取措施与您的防护建议。
4. 依法向监管部门报告。
5. 保留事件记录，用于复盘与改进。

## 十、协议的变更与终止

### 10.1 变更

出现下列情形，我们更新本协议并重新取得您的同意：
- 更换主机服务商或数据存储地；
- 新增境外接收方；
- 扩大出境数据范围；
- 法律要求变化导致合规路径调整。

一般性文字修订会在文档顶部更新日期，不触发重新同意。

### 10.2 终止

本协议随您注销账号或服务终止而终止。终止后，我们按《隐私政策》处理已出境的数据；法律要求保留的记录除外。

## 十一、适用法律与争议解决

1. 本协议适用中华人民共和国法律。
2. 因本协议产生的争议，双方应友好协商；协商不成的，提交运营者所在地有管辖权的人民法院诉讼解决。
3. 若您位于中华人民共和国境外，当地法律强制适用的个人信息保护条款不受本协议影响。
