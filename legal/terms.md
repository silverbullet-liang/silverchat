# 用户协议

## 一、协议的接受与适用范围

本协议由您与本服务的运营者（以下简称“我们”）订立。本服务名为 SilverChat，是一款支持端到端加密的即时通讯应用。

### 1.2 接受方式

您在选择“我已阅读并同意《用户协议》《隐私政策》《跨境数据传输协议》”并完成注册时，即表示您已完整阅读、理解并同意本协议全部条款。登录时我们同样要求勾选确认。

若您不同意本协议任何条款，请停止注册与使用。

本协议与以下文件共同构成完整约定：
- 《隐私政策》
- 《跨境数据传输协议》

- 《第三方共享清单》

上述文件与本协议具有同等效力。就个人信息保护事项，以《隐私政策》为准；就数据出境事项，以《跨境数据传输协议》为准。

我们可能因功能调整、法律变化或安全需要修订本协议。修订后：
1. 文档顶部标注新版本号与日期；
2. 重大变更（权利义务实质变化）通过站内弹窗通知，并要求您重新同意；
3. 未重新同意前，您可能无法继续使用部分或全部功能；

### 2.1 我们提供的功能

- 账号注册、登录、找回密码、多端登录管理；
- 好友搜索、申请、备注、星标、拉黑、删除；

## 三、账号规则

### 3.1 注册条件

1. 您应具备与所从事行为相适应的民事行为能力。未满 14 周岁不得注册；14–18 周岁应在监护人同意与指导下使用。
2. 您应提供真实、有效的注册信息（用户名、密码、昵称），不得冒用他人身份。
3. 用户名规则：2–20 个字符，支持中文、英文字母、数字与 `_ - . @ # $ & +`；不能以 `. _ -` 开头或结尾；不能包含空格与控制字符；大小写不敏感唯一；**注册后不可修改**（作为登录凭证）。
4. 昵称规则：1–16 个字符，不得违反本协议第四节。

### 3.2 账号安全

1. 您应妥善保管密码与设备，因保管不善导致的损失由您自行承担。
2. 发现账号被他人使用时，应立即修改密码（会强制所有设备重新登录）或通过安全问题重置密码。
3. 我们不会以任何形式向您索要密码。凡索要密码的行为均属诈骗。
4. 您应自行保管端到端加密私钥。**私钥仅存于您的浏览器，我们无法帮您恢复**。

### 3.3 账号使用限制

- 一人注册合理数量的账号，禁止批量注册、养号、售卖账号；
- 账号仅限您本人使用，不得出借、出租、转让、买卖；
- 账号不可继承。您去世后，账号将被注销，数据按《隐私政策》处理。

### 3.4 账号注销

1. 您可随时在「我 → 账号与安全 → 注销账号」发起注销，需输入密码确认。
2. 注销后：无法登录、好友关系解除、消息发送者匿名化、动态下架、媒体文件立即删除、登录凭证全部失效。
3. **注销不可恢复**。请在注销前自行保存需要保留的内容。
4. 协议同意记录与注销申请记录按法律要求保留 3 年，其余个人信息立即删除或匿名化。

## 六、隐私与数据

### 6.1 隐私保护

我们按照《隐私政策》处理您的个人信息。请您在注册前完整阅读该政策。

### 6.2 端到端加密的边界

您理解并同意：

1. **我们无法读取您的私聊明文**，因此无法对私聊内容进行主动审核、关键词过滤或内容恢复。
2. **我们无法恢复您的加密私钥**。私钥仅存于您的浏览器，清除浏览器数据、更换设备、重装系统均可能导致历史消息无法解密。
3. **我们无法提供消息明文**用于您与他人的纠纷举证。请在重要沟通中自行保存证据。
4. **服务器端加密的数据**（用户名、昵称、动态文字等）由服务器持有密钥，可在合法程序下解密；这部分数据不具备端到端加密的保护强度。
5. **元数据以明文存储**，包括通信关系、时间、消息类型与大小、群成员关系等。

### 6.3 数据备份

您应自行备份重要内容。我们不对因您误删、设备损坏、浏览器清理数据造成的内容丢失承担责任。
