# SilverChat

端到端加密的即时通讯应用，PHP 7.0 + MySQL，零构建、无框架、可直接部署到共享主机。交互形态参考移动端即时通讯产品（仿微信）。

> 消息正文与聊天媒体在浏览器加密，服务器只转发密文；用户名、昵称、动态等采用服务器端加密存储；媒体 7 天自动删除。

## 功能

**账号**
- 注册 / 登录 / 安全问题找回密码
- 多端登录管理、踢下线、修改密码、注销账号
- 用户名 `sc_` 对外 ID（不暴露内部自增 ID）

**好友**
- 按 `sc_` ID 精确搜索（不做模糊搜索）
- 好友申请、验证附言、接受 / 拒绝
- 备注、星标、拉黑、删除、黑名单

**单聊**
- 文本、图片、语音、视频、文件、表情、位置
- 已读回执、未读计数、置顶、免打扰、删除会话
- 2 分钟内撤回
- 端到端加密（X25519 优先，不支持时回退 P-256）

**群聊**
- 建群（上限 50 人）、邀请、踢人、退群、群主自动转让
- 群名称、群公告、群昵称、群号、仅邀请加入
- 群密钥由成员间 ECDH 逐人封装，服务器无法解封

**动态**
- 发布文字（≤1000 字）与图片（≤9 张）
- 点赞、评论、回复
- 可见范围：公开 / 私密 / 部分可见
- 动态图片服务器端加密存储，7 天删除

**安全**
- 端到端加密：X25519 / P-256 + HKDF-SHA256 + AES-256-GCM
- 加密安全码：双方带外核对，检测公钥被替换（中间人）
- 全字段保护：服务器端 AES-256-CBC + HMAC-SHA256（先验 MAC 再解密）
- 用户名盲索引（HMAC-SHA256），密码 bcrypt cost=12，Token 只存 SHA-256
- 限流、常量时间比较、严格 CSP、禁止内联脚本

**合规**
- 隐私政策 / 用户协议 / 跨境数据传输协议 / 个人信息收集清单 / 第三方共享清单
- 注册与登录强制勾选，记录版本、IP、UA、时间
- 协议版本升级后要求重新同意

**表情**
- B 站「小黄脸」离线内置（225 个，排除愚人节变体），运行时不请求 bilibili

**客服**
- 「我 → 客服」进入固定客服会话，会话顶部实时显示客服在线状态
- 客服账号登录后只进入工作台，回复文字与图片，不能使用其他功能

## 客服

- **用户入口**：「我 → 客服」，自动创建与客服的单聊会话；会话顶部状态条每 15 秒刷新，客服最近 90 秒内有活动即显示「客服在线」。
- **客服账号**：用户名 `kefu`，密码在安装时设置（安装表单的「客服初始密码」，或环境变量 `SC_KEFU_PASSWORD`）；留空则随机生成，并在安装完成页显示一次。仓库中不包含任何密码。
- **客服能力**：登录后固定进入「客服工作台」，只能查看咨询会话、回复文字与图片；访问其他页面会被前端重定向，其他接口由服务端直接拒绝（403）。
- **加密**：客服消息同样是端到端加密。客服首次登录时生成并上传公钥；若客服从未登录，用户端会提示「客服尚未上线」。
- **改密**：安装后可随时在服务器上修改：

```bash
php tools/set_kefu_password.php '新密码'
```

改密会清除客服账号的所有登录凭证，客服需重新登录。

## 技术架构

```
浏览器（Web Crypto 做端到端加解密）
   │ HTTPS
   ├── REST API ──> PHP 7.0（无框架，单入口路由）
   │                 ├── 账号 / 好友 / 群聊 / 动态 / 媒体
   │                 ├── 服务器端字段加密与解密
   │                 └── 每次请求顺带一小批媒体惰性清理
   └── 每 4 秒轮询 /api/poll.php（页面隐藏时 15 秒，失败指数退避）
MySQL（字段密文 / 哈希 / 端到端密文）
media/（聊天媒体密文 + 动态图片与头像的服务器端加密文件）
secrets/master.key（Web 根之外，字段加密主密钥）
```

- 无 WebSocket、无 Cron、无 Redis：短轮询 + 惰性清理，适配共享主机。
- 前端原生 JavaScript，无构建步骤、无 npm 依赖。
- 目标运行环境 PHP 7.0（不使用 7.1+ 语法）。

## 快速开始

环境要求：PHP 7.0+（扩展 `pdo_mysql`、`openssl`、`mbstring`、`gd`、`json`）、MySQL 5.7+ / MariaDB。

> **必须使用 HTTPS**：Web Crypto（`crypto.subtle`）只在安全上下文中可用。通过 `http://` 加域名或 IP 访问时，Chrome、Edge、Firefox、Safari 都会禁用它，页面会提示「需要 HTTPS 访问」。本地调试请用 `http://localhost` 或 `http://127.0.0.1`（这两个地址被视为安全上下文）。

```bash
# 1. 上传到站点根目录，确保 config/、secrets/、storage/、media/ 可写
# 2. 创建数据库（utf8mb4）
# 3. 浏览器访问 /install.php，填写数据库与站点地址
# 4. 安装完成后删除 install.php（已安装状态下它也会返回 404）
# 5. 访问首页注册第一个账号
```

命令行安装（适合本地或 CI）：

```bash
php install.php \
  --db_host=127.0.0.1 --db_port=3306 --db_name=silverchat \
  --db_user=silverchat --db_pass=secret \
  --site_url=http://localhost:8080 --force_https=0
```

安装会：建表 → 生成 `config/config.php` → 生成 `secrets/master.key`（32 字节）→ 导入内置表情 → 写 `storage/installed.lock`。

## 安全模型

| 层级 | 保护对象 | 密钥位置 | 能防什么 | 防不了什么 |
|---|---|---|---|---|
| 端到端加密 | 消息正文、聊天媒体 | 只在浏览器 | 服务器被入侵、拖库、管理员作恶 | 设备被控、浏览器被植入 |
| 服务器端加密 | 用户名、昵称、备注、群名、动态文字与图片、头像 | 服务器主密钥 | 数据库被单独拖走 | 整机沦陷（密钥与数据同被获取） |
| 不可逆哈希 | 密码、Token、安全答案 | 无 | 拖库后还原原始值 | 弱密码离线爆破 |

**诚实声明**：服务器端加密不是端到端加密。整机沦陷时只有端到端加密的数据仍然安全。元数据（谁与谁通信、时间、类型）不加密。端到端加密不验证身份，需通过「安全码」带外核对。

## 已知限制

- 无音视频通话、无支付、无消息漫游到新设备（私钥不离开原设备）。
- 换设备或清除浏览器数据会生成新密钥，历史消息无法解密，对方安全码会变化。
- 群密钥依赖成员在线分发；新成员加入后需由邀请者完成封装。
- 共享主机无法使用 WebSocket 与 Cron，实时性依赖 4 秒轮询。
- 动态图片为多接收者可见，采用服务器端加密（非端到端加密）。

## 上线前必须替换

1. `config/legal_versions.php` 中的版本号与更新日期（修改协议内容后必须提升版本）。
2. 站点名称与地址（安装时填写，或修改 `config/config.php`）。
3. 客服密码：安装时已设置或随机生成；如需更换，执行 `php tools/set_kefu_password.php '新密码'`。
